## Module 1: Prompt Fundamentals (Week 1-4)

### Leerdoel
> Na deze module schrijf je prompts die 3x betere output geven dan standaard vragen.

### Week 1: De 7 Bouwblokken

| Onderdeel | Inhoud | Tijd |
|-----------|--------|------|
| **Theorie** | Introductie 7 Bouwblokken framework | 15 min |
| **Bouwblok 1** | Rol toewijzen | 10 min |
| **Bouwblok 2** | Context geven | 10 min |
| **Bouwblok 3** | Taak beschrijven | 10 min |
| **Oefening 1** | Schrijf prompt met 3 bouwblokken | 15 min |
| **Template** | Basis prompt template | - |

**Oefening 1: Eerste Prompt**
```
Situatie: Je wilt een vacaturetekst laten schrijven

Opdracht: Gebruik bouwblok 1, 2 en 3 om een prompt te schrijven.
- Welke rol geef je de AI?
- Welke context is relevant?
- Wat is de exacte taak?

Lever in: Je prompt + de output
```

### Week 2: Bouwblokken Verdieping

| Onderdeel | Inhoud | Tijd |
|-----------|--------|------|
| **Bouwblok 4** | Format specificeren | 10 min |
| **Bouwblok 5** | Voorbeelden geven | 10 min |
| **Bouwblok 6** | Constraints toevoegen | 10 min |
| **Bouwblok 7** | Output verfijnen | 10 min |
| **Oefening 2** | Complete prompt met 7 bouwblokken | 20 min |
| **Template** | 7-Bouwblokken Master Template | - |

**Oefening 2: Complete Prompt**
```
Situatie: Je wilt CV's screenen op 5 criteria

Opdracht: Schrijf een prompt met ALLE 7 bouwblokken:
1. Rol: Wie is de AI?
2. Context: Wat is de situatie?
3. Taak: Wat moet er gebeuren?
4. Format: Hoe moet de output eruitzien?
5. Voorbeeld: Geef een voorbeeld
6. Constraints: Wat mag NIET?
7. Verfijning: Welke details zijn belangrijk?

Lever in: Je prompt + output + reflectie
```

### Week 3: Prompt Levels

| Onderdeel | Inhoud | Tijd |
|-----------|--------|------|
| **Theorie** | Simpel vs Medior vs Complex prompts | 15 min |
| **Level 1** | Simpele prompts (1-3 bouwblokken) | 10 min |
| **Level 2** | Medior prompts (4-5 bouwblokken) | 10 min |
| **Level 3** | Complexe prompts (6-7 bouwblokken) | 10 min |
| **Oefening 3** | Zelfde taak, 3 prompt levels | 25 min |
| **Template** | Prompt Level Selector | - |

**Oefening 3: Level Vergelijking**
```
Taak: Schrijf een LinkedIn outreach bericht

Opdracht: Maak 3 versies van dezelfde prompt:
- Simpel (1-2 bouwblokken)
- Medior (4-5 bouwblokken)
- Complex (7 bouwblokken)

Vergelijk de output. Wat is het verschil?
Wanneer gebruik je welk level?

Lever in: 3 prompts + 3 outputs + analyse
```

### Week 4: Praktijkopdracht Module 1

| Onderdeel | Inhoud | Tijd |
|-----------|--------|------|
| **Review** | Samenvatting week 1-3 | 10 min |
| **Opdracht** | Bouw je eigen prompt library | 45 min |
| **Feedback** | Peer review (optioneel) | 15 min |

**Praktijkopdracht: Prompt Library**
```
Bouw een persoonlijke prompt library met 5 prompts:

1. Vacaturetekst schrijven
2. CV screenen
3. LinkedIn bericht schrijven

5. Kandidaat samenvatting maken

Eisen per prompt:

Lever in: 5 prompts + 5 outputs + reflectie
```
